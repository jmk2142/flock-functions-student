# Instructor facilitation notes

These are suggestions for the instructor, not student-facing steps or required activities.

## Moment 01

Start with a prediction, then try it. The number is an argument. Ask what the function promises, without opening the simulation. The initial flock has 12 birds.

## Moment 02

Try a silent release, enable sound, then add the chirp. Test all three buttons. One chirp per call is different from one chirp per bird. The controls below edit fixed values inside the shared action.

## Moment 03

Before extraction, notice why releaseBirds would do too much for a preview. Extract, then test preview and release. Change the shared pitch: both now sound different. Moving the instructions should preserve the release behavior.

## Moment 04

Choose a meaning for the sound differences. Change only the Release 20 arguments, then compare all three. Preview uses the selected profile without adding birds. Extend with Codex: propose another occasion for the same sound, its two arguments, and what should stay unchanged.
